# Ассемблер УВМ — вариант 18 (этап 1)

CLI-ассемблер на Python для этапа 1 практической работы 3. Он читает
текстовый файл с командами варианта 18, переводит команды в промежуточное
представление (IR), проверяет значения и в обычном режиме записывает
машинные байты в файл.

## Требования

- Python 3.8 или новее
- Внешние пакеты не требуются

## Язык исходных команд

Одна команда на строку. Регистр команд не важен. Аргументы разделяются
пробелами или запятыми. Можно добавлять комментарии после `#` или `;`.

| Команда | Формат | Значение |
|---|---|---|
| `LOAD_CONST` | `LOAD_CONST B, C` | Записать константу C в память по адресу B |
| `READ_MEM` | `READ_MEM B, C` | Записать в B значение по адресу, хранящемуся в памяти по C |
| `WRITE_MEM` | `WRITE_MEM B, C` | Записать значение из памяти B в память C |
| `SHR` | `SHR B, C, D` | Логический сдвиг вправо: операнд из D и косвенный операнд через C, результат в B |

Также допускается запись операндов с именами, например `LOAD_CONST B=42 C=90`.
Числа можно писать в десятичном виде или с префиксом `0x` для
шестнадцатеричных значений.

## Тестовый пример

Файл `tests/data/test.asm`:

```asm
LOAD_CONST 42, 90
READ_MEM 914, 224
WRITE_MEM 873, 350
SHR 79, 183, 267
```

Это тестовые значения из спецификации варианта 18. В режиме `--test`
программа показывает IR: поля, значения, битовые смещения и ширины.

## Запуск

Из корневой папки репозитория:


- Windows: `run.bat`
- Linux/macOS: `bash run.sh`

Скрипты запускают тестовый пример в режиме отображения IR.

### Запуск вручную

Показать промежуточное представление:


```bash
python src/assembler.py tests/data/test.asm output.bin --test
```

Собрать бинарный файл:


```bash
python src/assembler.py tests/data/test.asm output.bin
```

## Тесты

Запустить автоматические проверки:


```bash
python -m unittest discover -s tests -v
```

Проверяются поля IR, тестовое кодирование команд и контроль переполнения
значений операндов.
